# images/screens — v2 보드 캡처 네이밍

캔버스의 v2 보드를 export 해 이 폴더에 둔다 (기준 이미지 — 수치가 다르면 `source/*.html`이 정답). 테마는 **cloud 기준 1장씩**, 테마 비교가 필요하면 `_<theme>` 접미사.

| 파일명 | 원본 보드 | 크기 |
| --- | --- | --- |
| `theme_tokens.png` | 디자인 기조 v2 · 테마 시스템 | 1440×1500 |
| `intro_desktop.png` / `intro_phone.png` | ① 인트로 v2 | 1440×900 / 390×844 |
| `planner_desktop.png` / `planner_phone.png` | ② 플래너 v2 | 1440×900 / 390×844 |
| `trips_desktop.png` / `trips_phone.png` | ③ 여행 목록 v2 | 1440×900 / 390×844 |
| `ai_sheet_desktop.png` / `ai_sheet_phone.png` | ④ AI 제안 시트 v2 | 1440×900 / 390×844 |
| `states_desktop.png` / `states_phone.png` | ⑤ 공통 상태 v2 | 1440×900 / 390×844 |

테마 변형 예: `planner_desktop_autumn.png`, `trips_phone_korea.png` (보드의 Tweaks ▸ theme, 또는 `source/*.html`의 우하단 셀렉터로 전환 후 캡처).

> 위 11장(cloud 테마)은 동봉되어 있다 — `source/*.html`을 그대로 렌더한 것(미리보기 셀렉터만 숨김). 테마 변형 캡처가 필요하면 셀렉터로 전환 후 직접 캡처.
