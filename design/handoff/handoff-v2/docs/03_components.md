# 03 · 컴포넌트 레시피 v2

치수는 dp/sp. 레이아웃 진실은 `source/*.html` (1px = 1dp), 색은 역할명으로 표기 — 실값은 tokens.json의 현재 테마. 상태별 렌더 예시는 `source/states_*.html`.

## 패널 (일정 패널 · 섹션 카드)

- 면 `card`, 테두리 **2dp ink**, radius 10, 섀도 **(3,3) blur0 `shadow`**.
- 머리에는 헤더 스트립: Desktop 패널 52, 카드 32~40, Phone 패널 44. 채움 = `h1→h2→h3` 로테이션(또는 의미색 — 오류 섹션은 `err`), 글자 흰 Jua, **아래 2dp ink 구분선**.
- 패널 내부 리스트 바탕은 `soft`, 안쪽 카드는 다시 `card` + 2dp ink.

## 방문지 카드 (플래너 리스트)

- 2dp ink / radius 10 / `card`. 머리띠 32 (`h` 로테이션): 흰 Jua 14 + **번호 배지** 20×20, radius 6, 흰 배경 + ink 글자.
- 본문 8×10 패딩: 시간 줄 12sp w600, 주소 11sp `sub`.
- **선택됨**: 테두리 3dp `accent`로 교체 + 머리띠 `accent` + 섀도 (3,3) 추가 + 머리띠 우측 흰 알약 배지 "선택됨" (11sp w700, ink 글자).
- **고정 시간**: 시간 줄 앞에 시계 아이콘 13, w700.

## 구간(경로) 칩

- 카드 사이, 왼쪽 들여쓰기 12에 **세로 커넥터 3×24** (도보 = accent 5/5 점선 패턴, 그 외 해당 역할색 실선) + 칩.
- 칩: 높이 26, radius 999, **1.5dp ink**, `card` 면, 12sp w600 ink. 수단 아이콘 14는 경로 역할색.
- '추정' 배지가 붙는 경우: 칩 내부 우측 `est` 알약 (1.5dp ink, 글자 #2A1D08 11sp).
- **재계산 필요**: 테두리 dashed + 글자 `sub`.

## 버튼

| 종류 | 치수 | 마감 |

| 주요 (AI 동선 최적화 · 수락 · 시작하기) | 높이 48~50 (인트로 58) | `accent` 채움 + 흰 Jua 15~18 + 2dp ink + 하단 섀도 (0,3) ink + **chamfer**: 우상단 8dp 사선 (radius 10과 병행 — 아래 클립 패스) |

chamfer 클립 (폭 W, 높이 H, 꼭짓점 radius 12, 사선 8): `M12 0 H(W−8) L W 8 V(H−12) A12 12 0 0 1 (W−12) H H12 A12 12 0 0 1 0 (H−12) V12 A12 12 0 0 1 12 0 Z`. Compose는 `GenericShape`로 동일 패스.

- **press**: translateY 2 + 하단 섀도 3→1, 80ms. **disabled**: 전체 50% + 섀도 제거.

## 마커 (지도 핀)

- 물방울 패스 36×44 (선택 44×54), 채움 = 카드 머리띠와 같은 로테이션 색, **외곽 2.5dp ink** (선택 3dp + drop-shadow (2,3) `shadow`).
- 내부 흰 원 r11 (선택 13.5) + 2dp ink, 번호는 **ink 글자 Jua 14 (선택 17)** — v1의 흰 글자·그라데이션 핀 폐기.
- 경로선: 지도 위 5dp, 도보 accent 점선 (2 on 11 off, round cap), 대중교통 h2, 자동차 h3 실선.

## 모달 / AI 시트 (Desktop 중앙 다이얼로그 780w)

- 딤 #000 34% → 다이얼로그 `card`, 2dp ink, radius 12, 섀도 **(5,5) #00000059**.
- 헤더 56: `accent` 채움, 흰 Jua 20 + 보조 12 w600 92%, 우측 **절약 배지**: 흰 알약 + 2dp ink, "−24분" Jua 18 ink + 전후 11 w700 `sub`.
- Phone은 하단 시트: 상단 radius 18, 상단 테두리만 2dp ink, 그랩바 36×4 ink 30%.

## 오류 배너 · 오프라인 필 · 스켈레톤 · 빈 상태 (`source/states_*.html`)

- **오류 배너**: `errSoft` 면 + **2dp `err` 테두리** + radius 9, 아이콘 `err`, 글자 ink 12 w600, 우측 고스트 "다시 시도". 콘텐츠는 유지한 채 리스트 상단 삽입.
- **오프라인 필**: 지도 위 중앙 알약 — 높이 34, `card` + 2dp ink + (0,3) `shadow`, Jua 13 ink, 아이콘 `sub`. 지도는 saturate 55%.
- **스켈레톤**: `skel` 블록 (radius 6), 카드 뼈대는 실제 카드와 같은 2dp ink 테두리 유지 — 머리띠 자리도 `skel`. 펄스 1200ms 2% 밝기 변화만.
- **빈 상태**: 마커 모양 일러스트 50 (soft 채움 + ink 외곽 + accent 십자) + Jua 16 제목 + 12 `sub` 2줄 + 주요 버튼.

## 접근성

터치 타깃 최소 48 (26 높이 칩은 히트 영역 확장), 포커스 링 = 2dp `accent` 외곽 오프셋 2, 모든 색 조합은 CONTRAST.md 검증값 준수.
