# 30 · 지도 스타일 v2 (MapLibre + OSM/OpenFreeMap)

v1의 중립 라이트 스타일을 유지한다 — **지도 타일은 테마를 따라가지 않는다**. 8종 테마가 전부 라이트 계열이고, 마커·경로선(역할색)이 테마를 표현하므로 타일까지 물들이면 과하다.

## 기준 스타일

- 베이스: OpenFreeMap `liberty` 계열을 라이트 그레이로 감산 — `assets/map/map_light.svg`는 그 톤의 목업(소스 html용 참고 이미지)이다. 실제 스타일 JSON 생성은 v1 도구 `tabiji/tools/gen_map.py` 파이프라인 참조 (v1 패키지 동봉분).
- 톤 가이드: 도로 #FFFFFF/#F0F2F5 · 땅 #ECEFF3 · 공원 #E4EEE2 · 물 #D8E8F4 · 라벨 #5B6878 (cloud의 `sub`와 동급 명도).
- 다크 지도는 v2 범위 밖 (다크 변형과 함께 2단계).

## 테마와의 접점 (타일 밖에서만)

- **지도 패널 테두리** 2dp `ink` + radius 10 — 테마의 ink를 따라간다 (지도가 "도감의 삽화 프레임"처럼 보이는 요소).
- 마커 채움·경로선: 01/03 문서의 역할색. 테마 전환 시 타일은 그대로, 오버레이만 크로스페이드.
- 선택적 테마 틴트 (원하면): 지도 위에 `paper` 색 4% 오버레이 한 장까지 허용 — 그 이상 금지.
- 오프라인: 타일 캐시 + `saturate(0.55)` 필터 + 오프라인 필 (03_components.md).
