# 00 · 디자인 원칙 v2 — "도감 같은 여행 수첩"

v1(맑은 하늘 위의 실버 테크 / 글래스)은 폐기한다. v2의 무드는 **도감(圖鑑)**: 두꺼운 잉크 테두리, 평평한 면 색, 색 머리띠가 달린 패널 — 손에 잡히는 수첩/카드 게임의 질감. 레퍼런스는 팀 내부 앱 PokeSix의 기조이며, Tabiji는 거기에 **사용자 선택형 테마 8종**을 얹는다.

## 핵심 규칙 (전 화면 공통)

1. **잉크 테두리** — 모든 패널·카드·버튼·칩은 `ink` 색 실선 테두리를 가진다. 패널 2dp, 칩 1.5dp, 선택 강조 3dp. 테두리 없는 떠 있는 요소는 없다.
2. **하드 섀도(블러 0)** — 그림자는 전부 **솔리드 오프셋**: 패널 `(3, 3) 0blur shadow(=ink 22%)`, 버튼 하단 `(0, 3) 0blur ink`, 모달 `(5, 5) 0blur #00000059`. 부드러운 블러 섀도·글로우 금지. Compose에서는 `Modifier.drawBehind`로 오프셋 라운드렉트를 먼저 그린다 (elevation 사용 금지).
3. **평평한 면** — 그라데이션·글래스(블러)·반투명 패널 금지. 면은 `paper / card / soft` 3단계 평색이 전부다. 유일한 투명 요소는 모달 딤(#000 34%)과 미계산 경로(45% 불투명).
4. **배경 스트라이프** — `paper` 위에 45° `stripe` 줄무늬 (Desktop 16dp 폭/간격, Phone 14dp). 콘텐츠가 올라가는 패널 내부에는 깔지 않는다.
5. **색 머리띠(헤더 스트립)** — 패널·카드 머리에는 테마의 `h1 → h2 → h3`(korea만 h4 포함) 로테이션 색을 채우고 **흰 Jua 글자**를 올린다. 머리띠 아래에는 반드시 2dp ink 구분선. 같은 화면에서 인접한 카드가 같은 머리색을 쓰지 않게 순환시킨다 ("살짝 알록달록"이 목표 — 무지개 금지).
6. **chamfer 모서리** — 주요(채움) 버튼만 우상단 모서리를 8dp 사선으로 깎는다 (v1에서 유지된 시그니처). 나머지 요소는 일반 라운드.
7. **눌림 = 가라앉기** — press 시 `translateY(2dp)` + 하단 섀도 3→1dp, 80ms. 스프링·바운스·스케일 금지 (20_motion.md).
8. **테마는 색만 바꾼다** — 테마 전환으로 변하는 것은 색 역할(role) 값뿐이다. 레이아웃·치수·타이포·아이콘은 8종 전체에서 동일 (01_tokens.md의 테마×역할 모델).

## 테마 시스템 개요

사용자가 설정에서 고른다. 기본은 **cloud(구름)** — 하늘하늘한 청색 계열.

| 묶음 | 테마 | 분위기 |
| --- | --- | --- |
| 기본 | `cloud` | 구름·하늘, 청색 계열 알록달록 |
| 사계절 | `spring` 벚꽃 / `summer` 바다 / `autumn` 단풍 / `winter` 설원 | 인트로 일러스트와 짝 |
| 나라 | `korea` 한지와 단청 / `china` 주홍과 옥 / `japan` 아이(藍)와 와시 | 여행지 국가 무드 |

- 다크 모드는 v2 범위 밖 — **테마별 다크 변형은 2단계**에서 설계한다. v2 구현은 라이트 고정.
- 지도 타일은 테마와 무관하게 중립을 유지한다 (30_map_style.md).

## 진실 소스 우선순위

`tokens/tokens.json` (수치·색의 최종 기준) → `source/*.html` (레이아웃 진실, 1px = 1dp) → `images/screens/` (참고용 캡처). 보드 CSS와 tokens.json의 색이 미세하게 다른 경우가 있는데(대비 검증 후 토큰만 어둡게 조정), **항상 tokens.json이 정답**이다 (01_tokens.md의 조정 기록).

## 접근성 기준 (v1과 동일)

본문·보조 글자 4.5:1, 흰 Jua 디스플레이(14sp+, 굵은 획)와 선·테두리 3:1, '추정' 배지 글자 4.5:1. 전 테마 × 전 조합 검증 결과는 `CONTRAST.md` (FAIL 0), 재검증은 `tools/contrast_check.py`.
