# 20 · 모션 v2

원칙: **가라앉고, 자르고, 크로스페이드** — 도감 무드에 맞게 기계적으로. 스프링·바운스·오버슈트·스케일 팝 금지. 이징은 전부 `cubic-bezier(0.2, 0, 0, 1)` (= Compose `FastOutSlowInEasing`과 유사한 감속), 카메라만 (0.4, 0, 0.2, 1).

| 토큰 | 시간 | 쓰임 |
| --- | --- | --- |
| micro | 120ms | 호버 틴트 · 체크 토글 · 칩 선택 |
| press | **80ms** | 버튼·카드 눌림: `translateY(2dp)` + 하단 섀도 3→1dp (뗄 때 역재생 120ms) |
| transition | 240ms | 시트 열림/닫힘 · 패널 접기 · 선택 전환 |
| themeSwitch | 240ms | **테마 전환 — 색만 크로스페이드**, 레이아웃·위치 애니메이션 없음 |
| camera | 600ms | 지도 카메라 이동 |

- **press 구현**: 오프셋과 섀도를 같은 트랜지션으로 — 섀도가 줄면서 내려앉아 "종이가 눌리는" 느낌. elevation 전환 금지.
- **테마 전환**: 역할색을 `animateColorAsState`(240ms)로 감싸거나, 전환 순간 스냅샷 비트맵 크로스페이드. 스트라이프 배경도 색만 변한다.
- **스켈레톤**: 1200ms 주기, `skel` 밝기 ±2% 사인 — 시머(이동 광택) 금지.
- **리스트 재정렬** (AI 수락 후): 각 행 240ms 위치 트윈 + 바뀐 행 머리띠 120ms 플래시 (`accent` → 원래 색).
- **인트로**: 10_intro.md의 시퀀스 표 (사분면 stagger 150, 스택 상승 600).
- **동작 줄이기 (접근성)**: 모든 전환 0ms 스냅, 파티클·패럴랙스·스켈레톤 펄스 끔. press의 translateY는 유지 (피드백이므로).
