# 13 · AI 제안 시트

기준 이미지: `images/screens/ai_sheet_desktop_light.png`, `ai_sheet_desktop_dark.png`, `ai_sheet_phone_light.png`, `ai_sheet_phone_dark.png`. 원본: `source/ai_sheet_desktop_light.html`, `source/ai_sheet_phone_light.html`.

## 역할

"AI 동선 최적화" 버튼을 누르면 서버가 돌려준 **변경안**을 사용자가 검토하는 화면. 원칙: (1) 변경 전후를 나란히, (2) 절약 시간을 크게, (3) **변경마다 이유 한 줄**, (4) 수락 / 일부 수락 / 거절. 고정 시간이 있는 방문지는 절대 옮기지 않는다는 것을 헤더에 명시한다.

## 상태 전이

| 행동 | 결과 |
| --- | --- |
| 수락 | 모든 체크된 변경 적용 → 시트 닫힘 → 플래너 리스트가 새 순서로 240ms 재배치(`animateItemPlacement`) → 지도 경로 다시 그림 |
| 일부 수락 | 체크된 것만 적용. 체크가 0개면 버튼 비활성 |
| 거절 | 아무것도 바꾸지 않고 닫힘. 제안은 24시간 캐시(다시 열기 가능) — 범위 밖, 더미로만 |
| 체크 해제 | 절약 배지의 시간이 해당 변경분만큼 즉시 재계산 (−24 → −18) 120ms 숫자 전환 |
