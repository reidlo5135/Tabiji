# 00 · 디자인 원칙 — "맑은 하늘 위의 실버 테크"

Tabiji(旅路)의 UI는 **차갑고 정돈된 금속성 표면** 위에 **밝은 하늘빛과 넓은 여백**을 얹는다. 캐주얼하지 않지만 무겁지도 않고, 지도 위에 가볍게 떠 있는 느낌이 목표다. 아래 다섯 원칙은 모든 화면·컴포넌트 판단의 기준이며, 토큰 수치보다 우선한다 (수치는 원칙을 지키는 선에서 조정 가능).

## 1. 절제된 금속성

- 은색은 **세로 그라데이션 한 겹**(`surface.silver.from → to`) 과 **상단 1dp 하이라이트 라인**(`line.highlight`)으로만 표현한다.
- 크롬 반사, 금속 텍스처, 다중 그라데이션, 입체 베벨은 쓰지 않는다. 눌림 상태도 그라데이션을 어둡게 한 한 겹(`surface.silver.pressed.*`) + 안쪽 그림자뿐이다.
- 은색이 쓰이는 곳: 보조 버튼, 마커 물방울, 번호 원, 로고 프레임, 일차 헤더의 접기 버튼. 그 외 표면은 글래스(`surface.glass`)다.

## 2. 공기감

- 지도 위의 패널·시트·검색 필드는 **반투명 글래스(72%) + 블러 16~24dp**로 지도가 비쳐 보인다.
- 블러를 지원하지 않는 플랫폼/기기에서는 **`surface.glass.solid`(92%)** 로 대체한다. 둘 다 같은 테두리(`line.subtle` 1dp)와 하이라이트를 가지므로 블러 유무가 레이아웃을 바꾸지 않는다.
- 여백은 넉넉하게: 패널 안쪽 16dp, 카드 안쪽 12dp, 섹션 사이 24dp. 밀도를 높이고 싶을 때는 여백이 아니라 접기(일차 헤더·패널)로 해결한다.

## 3. 포인트는 하나

- 강조색은 **스카이 시안 `accent.sky` 한 가지**. 주요 버튼 채움, 선택 테두리, 도보 경로, 선택 마커에만 쓴다.
- 의미색은 `route.transit`(대중교통), `route.drive`(자동차), `status.estimated`(추정), `status.error`(오류) 네 가지로 끝. 새 색을 추가하려면 이 문서를 먼저 고친다.
- `accent.sky` 위의 흰 글자는 대비 2.7:1로 접근성 기준에 미달한다. 그래서 **accent 채움 위 글자는 `accent.on`(어두운 남색)**, **밝은 표면 위 accent 글자·아이콘은 `accent.text`** 를 쓴다 (01_tokens.md 변경 기록 참고).

## 4. 지도가 주인공

- UI는 지도를 가리지 않는다. Desktop 패널은 **360dp 고정폭이지만 56dp 레일로 접히고**, Phone 바텀시트는 **접힘(96) / 절반(420) / 전체** 3단이다.
- 지도 컨트롤은 글래스 원형 버튼(48dp)으로 우하단에 세로로 모은다. 패널이 접히면 컨트롤이 패널 자리로 옮겨 가지 않고 그 자리에 머문다 (지도 우측 여백 24dp 기준).
- 지도 스타일은 실버 톤으로 채도를 낮추되 **도로 등급·물·공원의 명도 차이는 유지**한다 (30_map_style.md).

## 5. 각진 디테일

- **주요 버튼과 로고 프레임에만** 우상단 한쪽 모서리 chamfer(버튼 8dp, 로고 프레임 12dp)를 준다. 카드·칩·패널·보조 버튼은 둥근 모서리만.
- chamfer는 "이 앱의 가장 중요한 행동"을 표시하는 신호이므로 한 화면에 chamfer 버튼은 **하나**만 둔다 (AI 동선 최적화, 시작하기, 새 여행 만들기, 수락).

## 색만으로 의미를 전달하지 않는다

- 경로: 색 + **선 패턴**(도보 점선 / 나머지 실선).
- 상태: 색 + **아이콘·텍스트**("추정" 배지에 ≈ 아이콘, "재계산 필요" 텍스트, 고정 시간에 시계 아이콘 + "고정").
- 선택: 색 + **테두리 두께 변화**(1dp → 2dp) + 번호 원 채움.

## 레퍼런스 사용 기준

분위기 레퍼런스(밝은 하늘·실버 톤의 게임 메인 화면 등)는 느낌만 참고했다. 다른 회사의 로고, UI 프레임, 아이콘, 전용 폰트, 화면 구성, 캐릭터는 가져오지 않았으며, 이 패키지의 아이콘·아바타·일러스트·워드마크는 모두 오리지널이다.
