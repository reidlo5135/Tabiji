## Desktop 1440×900 (가변, 최소 1024×700)

```
┌──────────────────────────────────────────────────────────────┐
│ [검색 360×48] @ (24,24)                        ┌ 패널 360 ┐ │
│                                                 │ (24 여백)│ │
│   지도 (전체)                                   │ 일차 헤더│ │
│   마커·경로                                     │ 리스트   │ │
│                                                 │ (스크롤) │ │
│                                     [컨트롤 48] │ AI 버튼  │ │
│                                     @ right 408 └──────────┘ │
└──────────────────────────────────────────────────────────────┘
```

| 요소 | 위치 · 크기 |
| --- | --- |
| 지도 | `fillMaxSize`, 패널 뒤까지 깔림 (패널이 지도를 가리는 구조, 지도 패딩은 MapLibre `padding right = 408` 로 카메라 중심 보정) |
| 검색 필드 | left 24, top 24, 360×48 |
| 지도 컨트롤 | right 408 (= 24 + 360 + 24), bottom 24, 48 원 ×4 세로 gap 8: 내 위치 / 확대 / 축소 / 패널 접기 |
| 우측 패널 | right 24, top 24, bottom 24, 폭 360, 글래스 패널 16 (블러 20) |
| 패널 안 | 일차 헤더 72 (하단 선) · 리스트 `padding 12 16`, `Column(gap 6)` 스크롤 · 푸터 `padding 12 16 16` (상단 선) 버튼 328×48 + 안내 caption 11 |
| 패널 접힘 | 폭 56 레일, right 24. 컨트롤 right → 104. 240ms |

리스트 구성 순서: `VisitCard` 와 `SegmentChip` 이 번갈아 쌓임 (카드 N개, 칩 N−1개). 마지막 카드(숙소)는 주소 대신 "16:30 도착 예정".

창이 1024보다 좁아지면(태블릿·창 축소) 패널을 **하단 시트**로 전환한다 — Phone 규칙을 그대로 쓴다 (`WindowSizeClass.Compact/Medium`).

## Phone 390×844

| 요소 | 위치 · 크기 |
| --- | --- |
| 지도 | `fillMaxSize` |
| 검색 필드 | 상태바 아래 8 (예시 top 56), left/right 16, 높이 48 |
| 지도 컨트롤 | right 16, bottom = 시트 높이 + 16. 내 위치 / 확대 (축소는 핀치로) |
| 바텀시트 | 3단 96 / 420 / 전체. 상단 모서리 20 · 핸들 36×4 |
| 시트 안 | 핸들 영역 16 · 헤더 (패딩 4 16 10) · 리스트 `padding 12 16` gap 6 · 푸터 `padding 12 16 28` 버튼 358×48 |

리스트 스크롤 위치는 선택 마커와 동기화: 지도에서 마커 탭 → 시트를 절반으로 + 해당 카드로 스크롤 + 카드 선택 상태. 카드 탭 → 지도 카메라 flyTo 600ms + 마커 선택.

## 지도 위 요소

- 마커 앵커는 아래 꼭짓점. 번호는 방문 순서. 선택 마커는 z 최상.
- 경로는 `LineLayer` 3개 (walk / transit / drive) 로 분리해 패턴·색 지정. 미계산 구간은 `line-opacity 0.45`.
- 선택 구간(카드·칩 선택 시)은 `line-width 6`.
- 지도 라벨 언어: 여행지 국가에 맞춰 `name:ko` 우선, 없으면 `name` (30_map_style.md).
